How to Publish this Portal on Google Sites

Google Sites does not natively allow direct file-upload of standalone complex single-file apps (`index.html` with Tailwind & embedded JS) inside the page editor. However, you can easily embed or host it in two professional ways:

Method A: Free Hosting via GitHub Pages or Netlify (Recommended)

1. Click "Export JSON Progress" or save this code as `index.html`.
2. Upload `index.html` to a free static host like Netlify Drop (netlify.com/drop) or GitHub Pages.
3. In Google Sites, click Embed → select By URL → paste your live Netlify/GitHub link!

Method B: Direct HTML Embed Code in Google Sites

1. Open your Google Site.
2. Click Insert → Embed.
3. Choose Embed code and paste an `<iframe src="..."></iframe>` pointing to your hosted version.
